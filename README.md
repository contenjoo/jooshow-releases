# JooShow Desktop beta

Public installers and update feeds for JooShow Desktop. The application source is maintained in a separate private repository.

Download the latest beta from [Releases](https://github.com/contenjoo/jooshow-releases/releases/latest) or [joo.show](https://joo.show/#desktop).

- Mac: Apple Silicon, macOS 14+. Automatic version checks; install the new DMG manually until Developer ID signing is available.
- Windows: x64 NSIS installer. Automatically checks and downloads updates, then installs on normal app exit. Physical click-recording validation on Windows is still pending.
- Existing 0.9.1 users must install the update-enabled beta once. Existing local guides are retained.

This beta includes click recording, full/region capture, global shortcuts, guide editing and preview before export. Mac notarization and Windows code signing are not yet available. Report problems and feedback in [Issues](https://github.com/contenjoo/jooshow-releases/issues).
